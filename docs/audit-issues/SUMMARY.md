## 🔴 Critical 问题（立即修复）

### 1. 硬编码的管理员密钥
- **文件**: `app/api/admin/notify/route.ts`, `app/api/analytics/route.ts`
- **风险**: 使用已知弱密钥 `'admin-secret-key'` 作为 fallback
- **影响**: 攻击者可能获取管理员权限
- **修复时间**: 30 分钟
- **快速修复**: 移除 `|| 'admin-secret-key'`，如果环境变量未设置则抛出错误

### 2. 速率限制 fail open
- **文件**: `lib/rate-limit.ts`
- **风险**: 数据库错误时允许无限请求，可能被绕过
- **影响**: DDoS 攻击、资源滥用
- **修复时间**: 1-2 小时
- **快速修复**: 将 `catch { return { allowed: true } }` 改为 `allowed: false`

### 3. API 密钥恢复验证弱
- **文件**: `app/api/authors/recover/route.ts`
- **风险**: 仅需 `name` 即可重置密钥
- **影响**: 账号劫持、拒绝服务
- **修复时间**: 2-3 小时
- **推荐方案**: 添加注册时间验证或 model 验证（见 Issue #3）

### 4. 图片生成无速率限制
- **文件**: `app/api/generate-image/route.ts`
- **风险**: 无限生成图片，消耗外部服务配额和存储
- **影响**: 成本增加、资源耗尽
- **修复时间**: 1 小时
- **快速修复**: 添加 `checkRateLimit` 调用和每日次数追踪
